# Upstream provenance

Xeno's browser foundation is derived from [Nira Browser](https://github.com/prirai/nira-browser),
upstream commit `ef717b65071557e707ffea299aa9a6367f9730ac`.

Nira Browser is licensed under the Mozilla Public License 2.0. Its original license and
notices are retained in this repository. The application ID, visible product branding,
launcher artwork, project metadata and selected source URLs have been adapted for Xeno.

This migration intentionally prioritizes a proven browser core. Candy Browser's gesture-first
UI is a visual/interaction reference; its source is not copied because its repository uses
a noncommercial license.
