# Xeno experimental browser base: Candy Browser

This branch contains an imported Candy Browser source snapshot for isolated evaluation only.

- Upstream: https://github.com/sk2andy/candy-browser
- Imported upstream commit: bf69315acd7b35f335a45706f5d741a4cc9a5ddd
- **License discrepancy:** the upstream README and GitHub metadata identify MPL-2.0, but the current upstream `LICENSE` file contains PolyForm Noncommercial License 1.0.0. These terms conflict. Treat this source as uncleared for Xeno distribution or commercial use until the upstream maintainer resolves the discrepancy in writing.
- The source still has Candy package identity and branding; no Xeno rebranding has been applied.
- CI completed the upstream debug build, but no install/runtime test was performed on a physical device.
- This branch is not the selected long-term Xeno foundation while an unambiguously open-source GeckoView base is being evaluated.
- The stable Xeno branches are unchanged.
